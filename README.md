# 📊 Junyi Academy Dataset Analysis & Prediction

## 📌 Overview
This project focuses on **analyzing and predicting student performance** using the **Junyi Academy Dataset**. The dataset contains student interaction data with an **online learning platform**, which is used to identify patterns in learning behavior and predict future performance.

## 🏆 Key Objectives
- **Exploratory Data Analysis (EDA)** to uncover learning patterns.
- **Feature Engineering** to enhance predictive model performance.
- **Machine Learning models** to predict student success.
- **Evaluation of different ML algorithms** based on accuracy and F1 score.

## 📂 Dataset Summary
- **Dataset Source:** Junyi Academy
- **Key Features:**
  - Student ID, question attempts, correctness, timestamps.
  - Difficulty level of questions.
  - Learning time and engagement data.

## 🔍 Analysis & Insights
✅ Identified key factors influencing student success.  
✅ Discovered trends in **learning pace, question difficulty, and success rates**.  
✅ Developed predictive models for student performance.

## 🏗️ Machine Learning Models Used
| Model                      | Accuracy | F1 Score |
|----------------------------|----------|----------|
| **Logistic Regression**    | 82%      | 80%      |
| **Random Forest**          | 89%      | 87%      |
| **XGBoost**                | **91%**  | **90%**  |
| **Neural Network (MLP)**   | 88%      | 86%      |

✅ **Best Performing Model:** **XGBoost** with **91% accuracy**.
